# HelloToast

An Android app (Java) with a tap counter and a second screen. The Count button increments a number on screen, and the Say Hello button opens a second activity that greets you and shows the current count, passed between screens with an Intent extra.

## Concepts covered

- Click handlers bound from XML layouts
- Starting a second activity with an explicit Intent
- Passing data between activities with Intent extras

## Running it

Open the folder in Android Studio and run the `app` configuration on an emulator or device (Android 6.0+).

The enhancement write-up is in `docs/`.
